# Jadwal Ibadat dan Misa Natal 2026–2027
Website statis untuk **Paroki Jatiwaringin – Gereja Santo Leo Agung**.

## Isi folder
- `index.html` — konten dan struktur website.
- `style.css` — desain responsif untuk desktop dan ponsel.
- `script.js` — menu mobile, pencarian, dan filter jadwal.
- `assets/` — ilustrasi SVG sesuai tema Adven, Tobat, Natal, Keluarga Kudus, Syukur Akhir Tahun, Epifani, Natal Anak, dan UBK.

## Menjalankan secara lokal
Buka `index.html` di browser. Website tidak membutuhkan instalasi atau build tools.

## Publikasi ke GitHub Pages
1. Buat repository GitHub baru.
2. Unggah seluruh isi folder ini (bukan hanya file ZIP).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu alamat GitHub Pages muncul di bagian Pages.

## Catatan konten
Tanggal dan jam mengikuti rancangan jadwal yang diberikan panitia. Hari pada tanggal Sakramen Tobat diselaraskan dengan kalender: 1–3 Desember 2026 adalah Selasa–Kamis; 15–18 Desember 2026 adalah Selasa–Jumat. Mohon verifikasi seluruh jam dan detail liturgi sebelum publikasi resmi.
